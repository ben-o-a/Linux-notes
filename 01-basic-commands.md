# Basic Linux Commands

## Navigation
- `pwd` - show the folder I'm in
- `ls -la` - list all files, including hidden ones, with details
- `cd foldername` - move into a folder
- `cd ..` - move up one folder
- `cd ~` - go to my home folder

## Files and folders
- `mkdir name` - make a folder
- `mkdir -p a/b/c` - make nested folders in one go
- `touch file.txt` - create an empty file
- `cp source destination` - copy
- `mv old new` - move or rename
- `rm file` - delete a file
- `rm -r folder` - delete a folder and everything in it (careful)

## Reading files
- `cat file` - print a file
- `less file` - read a long file page by page (q to quit)
- `man command` - the manual for any command
